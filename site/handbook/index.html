Render a session with the CLI.

Use your own .entrain session or build one in the Studio. The local CLI renders evolving rain, wind and surf. The published v0.2.0 release plays looped rain and has no wind or surf.

  1. Get the local CLI. On Linux x86-64, download the matching executable and run chmod +x ./entrain in its folder. On another platform, open this source checkout and build with Go: go build -o entrain ./cmd/entrain. On Windows build entrain.exe and use .\entrain.exe.
  2. Build or edit a session. Open the Studio and choose a background, a length, and optional cues. To edit the score directly, open the .entrain source, change the text, and choose Apply source. Press Play to hear the applied settings. Preview volume controls the browser only.
  3. Save and render. Copy or download the displayed text, including your edits and comments. Place the file beside the executable and run the command shown in the editor. For a file named rain-bell.entrain, run ./entrain render rain-bell.entrain -o rain-bell.wav, then open the WAV in an audio player. For timed cues, use sections with their own start, duration and fades. Use Preview entrance to audition a section before rendering. CLI guide · Native session reference.
entrain · install
# Build the matching local CLI from this source checkout
$ go build -o ./entrain ./cmd/entrain
$ ./entrain mix --help

# Earlier release: v0.2.0 archives with the original rain loop
macOS · Apple silicon · macOS · Intel · Linux · x86-64 · Linux · ARM64 · Windows · x86-64
all releases
# A saved Studio session
$ ./entrain render rain-bell.entrain -o rain-bell.wav

# The same six-minute sound directly from the CLI
$ ./entrain mix rain --cue bell --cue-volume 50 --cue-interval-ms 900 --duration 6m -o rain-bell.wav

# Wind and surf also accept a cue; omit --cue for the bed alone
$ ./entrain mix surf --cue bell --duration 12m -o surf-bells.flac

# Save editable source without rendering audio
$ ./entrain mix rain --cue bell --duration 20s --save-session my-rain.entrain

# Inspect a scheduled cue from the included timeline example
$ ./entrain render examples/rain-bell-timeline.entrain --dry-run

# A background on its own
$ ./entrain mix pink --duration 10m -f flac -o pink.flac

# A legacy .sbg score from the source checkout
$ ./entrain render examples/focus-40-pink.sbg -L 0:30 -o focus.wav
# carriers, beat frequency and confidence per pair
$ beatscope focus.wav
$ beatscope focus.flac --json
$ beatscope focus.wav --min-confidence 0.6

# reads WAV (16/24-bit) and FLAC. MP3/OGG: convert to WAV first —
# no MP3 decoder in-tree, by design.
$ noisemaker pink 30m -o bed.wav
$ noisemaker brown 1:30:00 -o bed.flac -b 24
$ noisemaker alpha 2h --alpha 1.4 --level 0.12 --seed 7 -o drift.wav

# white, pink, brown — or any 1/f^α slope with --alpha.
# default level 0.155 RMS, calibrated to sit under binaural tones.
# deterministic with --seed.
formats -f wav|flac|mp3 depth -b 16|24 mp3 bitrate -q ≤ 320 length -L h:mm[:ss] output -o file
