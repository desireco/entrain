The SBaGen family

The new SBaGen stands on the shoulders of the original. If you are exploring brainwave audio, all three are worth knowing — here is the lineage.

The original · 1999

SBaGen

by Jim Peters

The classic sequenced binaural-beat generator: powerful, battle-tested C from another era, GPLv2, and the .sbg format that still defines the workflow. It remains the reference implementation — the new SBaGen validates its output against it.

The fork · modern builds

SBaGen+

maintained by Ruan Klein

A community fork that keeps the original alive on modern systems: fresh binaries for Linux, macOS and Windows, Docker images, and isochronic tones on top of binaural beats. Its own development has paused — the ideas continue in its successor SynapSeq.

SBaGen

clean-room Go, MIT licensed

The workflow continues: reads .sbg today, authors a typed TOML format next. Renders WAV / FLAC / MP3 with true tone continuity, and ships beatscope so you can verify what any renderer put in a file. Implemented by the entrain project.

What SBaGen does

One static binary, four subcommands, no cgo in the core pipeline.

♫.sbg compatible

Binaural tone-sets, pink/white/brown beds, NOW and relative times, nested blocks — and sbagen's 30-second crossfades with real tone continuity across changeovers.

▤Modern output

WAV and FLAC at 16/24-bit (dithered), MP3 up to 320 kbps. Float64 pipeline, deterministic renders — the same session always produces the same bytes.

🎧Noise palette

White, pink and brown noise with correct spectral slopes and decorrelated stereo — plus arbitrary 1/fα slopes via noisemaker.

🔍beatscope

Analyze any audio file — carriers, beat frequency, confidence per pair. A trust-but-verify tool for entrain, sbagen, or anything else.

⚡Instant to try

Pure Go, zero configuration: go install or grab a release binary for Linux, macOS and Windows.

⚖MIT licensed

Embed it anywhere, ship it in products. Rendered audio carries no license — your output is yours.

Quick start

Install, render, verify — all from the terminal.

# install
go install github.com/desireco/entrain/cmd/entrain@latest
go install github.com/desireco/entrain/cmd/beatscope@latest

# render an existing .sbg session
entrain render focus.sbg                 # default WAV; -f mp3 / -f flac, -b 24 for 24-bit
entrain focus-10 --dry-run               # preview the timeline plan first

# verify what ended up in the file
beatscope focus.wav

The CLI and engine live in the entrain project — a clean-room Go implementation of the SBaGen workflow.

A minimal session — one hour of 40 Hz gamma with a pink-noise bed:

## One-hour focus: 40 Hz gamma + 24 Hz beta over pink noise
all-off: -
focus:   pink/20 180+40/30 320+24/25

0:00:00  focus
1:00:00  all-off

🎧 Headphones required — binaural beats collapse on speakers. Keep the volume low; the tones should sit just above the noise bed.

Questions

Is this SBaGen affiliated with the original?

No. The new SBaGen is an independent clean-room reimplementation — no original code was read or copied, and it is not endorsed by Jim Peters. For the classic tool itself, see uazu.net/sbagen and the SBaGen+ fork. The implementation lives in the entrain project.

Can I use the rendered audio commercially?

Yes. entrain is MIT licensed and rendered audio carries no license — the GPLv2 covers the original SBaGen program, not the audio it or entrain produces.

What's next?

A native TOML session format ("trains"), EMDR bilateral voices, live playback, and a web player — the roadmap lives in the README.
