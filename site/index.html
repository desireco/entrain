Inside the engine

Pure Go in the core pipeline.

Packages you can lift, a binary you can ship.

01 Synth core

Phase-continuous sine oscillators, binaural L/R pairing, equal-power crossfades and amplitude glide envelopes — retuning never clicks. Float64 end-to-end.

02 .sbg reader + planner

Tone-sets, absolute / NOW / relative times, nested blocks — and sbagen's 30-second changeover crossfades with true tone continuity across segments.

03 Codec stack

WAV (go-audio), FLAC (mewkiz, bit-exact) and MP3 (pure-Go Shine, level-matched). Shared clip → TPDF-dither → quantize stage, 16/24-bit, deterministic.

04 Noise DSP

White, pink and brown noise with correct spectral slopes, decorrelated stereo and calibrated bed loudness — plus FFT-shaped 1/fα slopes in noisemaker.

05 beatscope

STFT carrier/beat detection with L/R pairing and window-voted confidence. Cross-engine validated against sbagen — all five brainwave bands match.

5/5 MATCH
06 MIT licensed

No SBaGen code anywhere — derived from public DSP technique and behavioral comparison. Embed it anywhere, including commercial use.

Handbook

Install, render, verify, generate.

All from the terminal.

entrain · install
# from source
$ go install github.com/desireco/entrain/cmd/entrain@latest
$ go install github.com/desireco/entrain/cmd/beatscope@latest
$ go install github.com/desireco/entrain/cmd/noisemaker@latest

# or grab a prebuilt binary — each tarball carries entrain,
# beatscope and noisemaker, with sha256 checksums alongside:
macOS · Apple silicon · macOS · Intel · Linux · x86-64 · Linux · ARM64 · Windows · x86-64
all releases
# the basics: .sbg → WAV (default)
$ entrain render focus.sbg
# 30 minutes only, custom output file
$ entrain render focus.sbg -L 0:30 -o focus-30min.wav
# lossless FLAC at 24-bit
$ entrain render focus.sbg -f flac -b 24
# MP3 at 320 kbps
$ entrain render focus.sbg -f mp3 -q 320
# preview the timeline plan + lint warnings — no audio written
$ entrain focus-10 --dry-run
# carriers, beat frequency and confidence per pair
$ beatscope focus.wav
$ beatscope focus.flac --json
$ beatscope focus.wav --min-confidence 0.6

# reads WAV (16/24-bit) and FLAC. MP3/OGG: convert to WAV first —
# no MP3 decoder in-tree, by design.
$ noisemaker pink 30m -o bed.wav
$ noisemaker brown 1:30:00 -o bed.flac -b 24
$ noisemaker alpha 2h --alpha 1.4 --level 0.12 --seed 7 -o drift.wav

# white, pink, brown — or any 1/f^α slope with --alpha.
# default level 0.155 RMS, calibrated to sit under binaural tones.
# deterministic with --seed.
formats -f wav|flac|mp3 depth -b 16|24 mp3 bitrate -q ≤ 320 length -L h:mm[:ss] output -o file
Plain text by design

Anatomy of a session.

A session is a few lines of plain text you can read, edit and version — no proprietary format, no binary blobs.

focus-40-pink.sbg
## One-hour focus: 40 Hz gamma over a pink-noise bed
all-off:
-
focus-40:
pink/20  180+40/30
 
0:00:00  focus-40
1:00:00  all-off
0:00:00 · focus in, 30 s changeover crossfade1:00:00 · all-off

01Tone-set line

carrier+beat/amplitude — amplitudes on a 0–100 scale, keep the sum under 100. The engine pairs L/R carriers for a true binaural beat.

02Schedule lines

time name — absolute, NOW, or +mm:ss relative.

03Changeovers

Crossfades happen automatically — 30 seconds, equal-power, with true tone continuity across segments.

04Session library

A small, growing set ships in the repo under examples/ — use as-is or edit in any text editor. Copy one, tweak the numbers, make it yours.

focus-40-pink 40 Hz γ over pink meditate-alpha 10 Hz α · soft pink sleep-delta 3 Hz δ · brown pink-bed an hour of pure noise
Questions

Asked, answered.

Why a rewrite?

SBaGen (Jim Peters) is wonderful 2000s software — powerful, battle-tested, and GPLv2 with a bespoke C codebase. Entrain keeps the functionality and modernizes everything around it: permissive license, static binaries, modern formats. The full rationale is in the migration plan.

Is Entrain affiliated with SBaGen?

No. Entrain is an independent clean-room reimplementation — no SBaGen code was read or copied, and it is not endorsed by Jim Peters. The original tool and its forks have their own SBaGen page.

What's next?

A native TOML session format ("trains"), EMDR bilateral voices, live playback, and a web player — see the roadmap.
