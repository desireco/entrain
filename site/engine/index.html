The entrain engine.

A clean-room Go reimplementation of the SBaGen workflow — the engine behind the new SBaGen. It renders .sbg sessions to WAV, FLAC and MP3, and verifies what any renderer put in a file with beatscope.

Get started Releases GitHub 
$ entrain focus-10 -f mp3
focus-10.mp3 · 40 Hz γ + 24 Hz β over pink noise · 320 kbps

Inside the engine

Pure Go, zero cgo in the core pipeline — packages you can lift, a binary you can ship.

♫Synth core

Phase-continuous sine oscillators, binaural L/R pairing, equal-power crossfades and amplitude glide envelopes — retuning never clicks. Float64 end-to-end.

📜.sbg reader + planner

Tone-sets, absolute/NOW/relative times, nested blocks — and sbagen's 30-second changeover crossfades with true tone continuity across segments.

▤Codec stack

WAV (go-audio), FLAC (mewkiz, bit-exact) and MP3 (pure-Go Shine, level-matched). Shared clip → TPDF-dither → quantize stage, 16/24-bit, deterministic.

🎧Noise DSP

White, pink and brown noise with correct spectral slopes, decorrelated stereo and calibrated bed loudness — plus FFT-shaped 1/fα slopes in noisemaker.

🔍beatscope

STFT carrier/beat detection with L/R pairing and window-voted confidence. Cross-engine validated against sbagen — 5/5 MATCH.

⚖MIT licensed

No SBaGen code anywhere — derived from public DSP technique and behavioral comparison. Embed it anywhere, including commercial use.

Quick start

Install, render, verify — all from the terminal.

# install
go install github.com/desireco/entrain/cmd/entrain@latest
go install github.com/desireco/entrain/cmd/beatscope@latest
go install github.com/desireco/entrain/cmd/noisemaker@latest

# render an existing .sbg session
entrain render focus.sbg                 # default WAV; -f mp3 / -f flac, -b 24 for 24-bit
entrain focus-10 --dry-run               # preview the timeline plan first

# make standalone noise beds
noisemaker brown 30m -o bed.flac
noisemaker alpha 1h --alpha 1.4

entrain is the engine; SBaGen is the public face. The roadmap and package docs live in the repository README.

Questions

Why a rewrite?

SBaGen (Jim Peters) is wonderful 2000s software — powerful, battle-tested, and GPLv2 with a bespoke C codebase. entrain keeps the functionality and modernizes everything around it: permissive license, static binaries, modern formats. The full rationale is in the migration plan.

Is this affiliated with SBaGen?

No. entrain is an independent clean-room reimplementation — no SBaGen code was read or copied, and it is not endorsed by Jim Peters. For the classic tool, see uazu.net/sbagen; for the community fork, see SBaGen+.

What's next?

A native TOML session format ("trains"), EMDR bilateral voices, live playback, and a web player — see the roadmap.
