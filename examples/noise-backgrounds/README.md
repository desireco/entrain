# Noise backgrounds

Three continuous six-minute stereo tracks. Each is made from seeded noise
generated by Entrain's `noisemaker`.

| Track | Sound |
| --- | --- |
| Pink Noise | A warm, partly centered pink bed with a wider band of air that rises and falls slowly. |
| White Noise | A steady, filtered white-noise bed with softer highs and a little movement in the upper band. |
| Soft Rain | A synthetic shower with a low wash, a finer hiss, and independently varying texture on each side. |

From the Entrain repository, run the following command with Bash, Go, and
FFmpeg (including libmp3lame) installed.

```sh
./examples/noise-backgrounds/render.sh
```

The script writes a 24-bit stereo FLAC, a full-length 320 kbps MP3, and a
30-second MP3 excerpt per track to `output/noise-backgrounds/`. To build one
track in a different directory, pass its name and the destination.

```sh
./examples/noise-backgrounds/render.sh pink ./renders
```

The names are `pink`, `white`, and `rain`. Each track has its own sound
recipe. FFmpeg shapes the 48 kHz source, then Entrain imports it into the
shared 44.1 kHz session. A fixed gain targets −24 LUFS with at least 3 dB
of true-peak headroom. The excerpt comes from 1:00–1:30 of the finished
master, with short tapers at its two boundaries.

## Bundled loops

The Studio and the command-line soundscape builder share lossless stereo
assets in `site/audio/`. To rebuild them, run
`./scripts/render-studio-audio.sh` from the repository. The script uses the
full-length masters in `output/noise-backgrounds/` and generates any
missing ones. You can also pass a master directory as the first argument.

Each background loop is a 60-second excerpt. Two seconds of overlapping
audio carry the texture across the repeat. The optional isolated cues each
contain eight complete left/right cycles in ten seconds. Their lower level
and the quieter copy in the opposite ear leave room for the background.
