Inside the engine

Pure Go in the core pipeline.

Packages you can lift, a binary you can ship.

01 Synth core

Phase-continuous sine oscillators, binaural L/R pairing, equal-power crossfades and amplitude glide envelopes — retuning never clicks. Float64 end-to-end.

02 .sbg reader + planner

Tone-sets, absolute / NOW / relative times, nested blocks — and sbagen's 30-second changeover crossfades with true tone continuity across segments.

03 Codec stack

WAV (go-audio), FLAC (mewkiz, bit-exact) and MP3 (pure-Go Shine, level-matched). Shared clip → TPDF-dither → quantize stage, 16/24-bit, deterministic.

04 Noise DSP

White, pink and brown noise with correct spectral slopes, decorrelated stereo and calibrated bed loudness — plus FFT-shaped 1/fα slopes in noisemaker.

05 beatscope

STFT carrier/beat detection with L/R pairing and window-voted confidence. Cross-engine validated against sbagen: the analyzer detected matching beat frequencies in five reference recordings.

Questions

Asked, answered.

Why a rewrite?

SBaGen (Jim Peters) is wonderful 2000s software — powerful, battle-tested, and GPLv2 with a bespoke C codebase. Entrain keeps the functionality and modernizes everything around it: permissive license, static binaries, modern formats. The full rationale is in the migration plan.

Is Entrain affiliated with SBaGen?

No. Entrain is an independent clean-room reimplementation — no SBaGen code was read or copied, and it is not endorsed by Jim Peters. The original tool and its forks have their own SBaGen page.

How do I save a Studio mix?

Download the .entrain session in the Studio and run the command shown beside it with the local executable. This build generates evolving rain, wind and surf. To reproduce v0.2.0 rain, use ./entrain mix rain-loop.
