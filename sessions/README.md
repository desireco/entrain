# Sessions

Your personal session files live here. Everything in this folder is
gitignored — sessions stay local — except this README and the
`.gitignore` itself, which keep the folder present in git.

Drop any `.sbg` file here and render it:

```sh
entrain render sessions/my-session.sbg -f mp3
```

For ready-made starting points see `examples/` — those are tracked and
shipped with the repo. Copy one into this folder and tweak the numbers.
