## Entrain CLI v0.3.0

Render the rain, wind and ocean surf you can build in the [Studio](https://entrain.cc/studio/). Download a `.entrain` session there and render it offline with this release. Pink noise, white noise, alternating bell/tone/noise cues, cue levels and spacing, and timed cue sections are all included.

### Added

- Continuous generated rain, wind and surf evolve for the full session duration. `--seed` and the native `seed` field select repeatable variations.
- Exact native-session excerpts use `--start` with `-L`. They retain the original cue timeline and are the corresponding slice of a full WAV or FLAC render.
- MP3 files carry the session title and encoder metadata.
- Archives now include seven examples, including evolving rain and wind/surf sessions with timed bells.

### Rain compatibility

`rain` now selects the evolving generator. Existing `.entrain` files naming `rain` produce a different background in v0.3.0. Use `rain-loop` in the mix command or native file to reproduce the original v0.2.0 rain. Pink and white retain their mastered minute loops. Legacy `.sbg` files continue through the existing renderer. The default seed preserves the current Studio's original rain, wind and surf performances.

### Install

Download the archive and adjacent SHA-256 checksum for your platform, extract it, and follow the included README. Archives contain Entrain, Beatscope, Noisemaker, the MIT license and editable examples. Linux x86-64 packages are exercised by the release workflow. The remaining four platform packages are cross-compiled.

Or install the renderer with Go:

```sh
go install github.com/desireco/entrain/cmd/entrain@v0.3.0
entrain version
```

### Render a Studio file

Save the source as `my-session.entrain`, then run:

```sh
entrain render my-session.entrain --dry-run
entrain render my-session.entrain -o my-session.flac
entrain render my-session.entrain --start 12s -L 30s -o my-session.excerpt.wav
```

The final command ends at the session's endpoint if fewer than 30 seconds remain. All audio assets and generators are inside the executable, so rendering works offline from any directory.
