## Entrain CLI v0.2.0

Render pink noise, white noise or synthetic rain offline with optional alternating tone, bell or noise cues. Set cue level and spacing independently, then save a reproducible TOML session with `entrain mix --save-session`. A native timeline can introduce and fade cues within a continuous background. Existing `.sbg` sessions still render.

Download the archive and its matching SHA-256 checksum for your platform. Extract the archive and open its README for commands that use the included examples. It includes Entrain, Beatscope and Noisemaker.

To install the renderer with Go:

```sh
go install github.com/desireco/entrain/cmd/entrain@v0.2.0
```
